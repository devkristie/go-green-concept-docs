## Plugins Used

**Public Post Preview** – Allows draft pages to be previewed via a public link.

**Yoast SEO** – Provides search engine optimization tools, including focus keyphrases, meta titles, and meta descriptions for each page, helping improve visibility on Google and other search engines.

**Happy Elementor Addons** – Adds extra Elementor widgets and styling options, used for hover effects and other visual enhancements.

**Prime Slider** – Adds slider widgets for Elementor, used to create responsive image and content sliders within the page builder.

**Duplicate Page** – Allows pages to be duplicated.

**EWWW Image Optimizer** – Optimizes images to reduce file size, improve page loading times, and generate WebP versions for faster delivery.

**Updraft Plus** – Backup plugin used to create and restore full website backups, including files and the database.

**Elementor** – Page builder used to design all pages. Pre-installed on the site.

**Ultimate Addons** for Elementor (UAE) – Adds additional Elementor widgets, including the Header & Footer Builder used for the site footer. Pre-installed on the site.

**SureForms** – handles the contact form on the Contact page. Pre-installed on the site.

### Site Structure

**Header:**
Appears on all pages; includes primary navigation.
The website header is managed through WordPress Appearance → Customize → Header.
**_Steps to edit:_**

- Go to WordPress Dashboard → Appearance → Customize
- Select Header
- Make changes as needed to the Primary Header or Off-Canvas Menu
- Click Publish to apply changes site-wide

> **Note:** Unlike the footer, the header does not rely on Ultimate Addons for Elementor, and is edited via the theme Customizer.

**Content Placement:**  
Ensured that content was correctly separated and placed on their respective pages, improving clarity and preventing content from visually merging.
Renamed Elementor structure to meaningful descriptive names for easier maintenance and clarity.

**Footer:**
Appears on all pages; includes website navigation, donation link, social media links, legal links (Privacy Policy and Accessibility Statement), copyright statement, company legal statement.
The website footer is managed using the Header & Footer Builder from the Ultimate Addons for Elementor plugin.

**_Steps to edit:_**

- Go to WordPress Dashboard
- Navigate to UAE → Header & Footer Builder
- Select the Footer template
- Click "Edit with Elementor"

> **Note:** Both header and footer are global Elementor templates, ensuring consistent branding and navigation across the site.

## Website Migration

The website was migrated from Spaceship to SiteGround (hosting purchased by the client).

Domain registration remains managed via Names.co.uk, with DNS now pointing to SiteGround.

A fresh WordPress installation was created on SiteGround and the full site was restored using an UpdraftPlus backup.

### Email Configuration & Authentication

Configured and validated email authentication records including MX, SPF, DKIM, and DMARC via SiteGround DNS.

SpaceMail records were integrated and verified successfully.

DMARC policy updated from p=none to p=quarantine to improve anti-spoofing protection.

Email delivery was tested and confirmed via:

- Gmail
- Outlook
- Contact form submissions

Authentication and DNS propagation were verified using MXToolbox and WhatsMyDNS.

### Post-Migration Setup

All plugins were updated following migration.

SiteGround caching system was cleared and site functionality re-tested.

Navigation/menu structure was repaired following migration:

- Fixed broken header links
- Corrected page associations and slugs

All pages, links, and forms were tested to confirm full functionality before final handover.

### Notes

Email configuration (MX and related DNS records) was updated to support SiteGround mail routing, while maintaining separation between website and email services.

Website hosting is now fully managed on SiteGround, while email services remain on SpaceMail.

DNS configuration separates website and email services correctly.

## Issues & Observations During Implementation

**Home Page hero H1 outline fix**

Issue:
Original H1 used Elementor Text Stroke, which did not render consistently on mobile or live previews.

Solution:
Fixed by adding text-shadow in Additional CSS to mimic the stroke around the letters.

Ensures consistent appearance across all devices while keeping multi-color spans intact.

**Home Page hero H1 responsive fix**

Issue:
The “Go Green Concept” H1 overflows the hero image on very small screens (≤320px).

Solution:
Shrink font-size between 278px–320px to keep text inside the hero.
Hide H1 completely below 278px to prevent layout issues.

Ensures the hero text is readable and layout-safe on all devices.

**Fix for contact form button styling**

Issue:
Submit buttons on the form were using default SureForms styling (common.min.css) that could not be overridden via Additional CSS.

Solution:
Custom CSS was added directly in the Form Settings → Custom CSS field of the specific form. This overrides the global SureForms styles only for this form, without touching plugin or theme files.

Applied CSS Example:

```css
#srfm-submit-btn {
  padding: 12.5px 30px;
  background-image: linear-gradient(to bottom, #54b435, #3f8d02);
  color: #fcfcfc;
  font-family:
    Albert Sans,
    Arial;
  font-size: 1.2rem;
  font-weight: 600;
  letter-spacing: 0.5px;
  text-transform: capitalize;
  border: none;
  outline: none;
  border-radius: 30px;
  box-shadow: rgba(0, 0, 0, 0.5) 0 0 10px;
}
```

> **Note:**
> Only affects this form.
> No additional plugins or theme edits were required.
